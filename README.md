# IA-Gen.-Prompts
Entrega Final IA Gen. Prompts Coderhouse 2026
Sistema basado en Fast Prompting y Python que asiste a Contadores Públicos y Peritos en la generación automatizada de borradores de liquidaciones laborales y previsionales en la provincia de Jujuy. Utiliza modelos de texto-texto (OpenAI GPT) para la redacción técnica y cálculo, y modelos de texto-imagen (NightCafe/Midjourney) para la generación de gráficos explicativos. Incluye validación humana obligatoria, registro de costos/tokens y una interfaz gráfica básica.
